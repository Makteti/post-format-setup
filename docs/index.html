How to use it

No technical knowledge needed.

  1. Download

    Click Download for Windows. If your browser asks, choose Keep.

  2. Run

    Right-click PostFormatInstaller.ps1 and choose Run with PowerShell. On Windows 11 it's under Show more options. Don't use "Run as administrator".

  3. Pick apps

    Click the apps you want. Use search or the category list to find them quickly.

  4. Install

    Click Install and watch each app finish. Close the window when it says Finished.

Windows will ask for permission for some apps

Apps that install for every user on the PC trigger a Windows prompt: "Do you want to allow this app to make changes to your device?" Before clicking Yes:

  • Check that the program name matches an app you picked, for example "Steam Setup" while Steam says Installing.
  • Check that the verified publisher is the company you expect, for example Valve Corp. or Discord Inc.
  • If anything doesn't match, or the publisher shows as Unknown, click No. That app is skipped and the rest carry on.
