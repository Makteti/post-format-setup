Reinstall all your apps after a fresh Windows install

Post-Format Setup is a small program for the moment right after you've formatted your PC. Tick the apps you use, press Install, and it downloads and installs them one by one while you do something else. No hunting through websites, no clicking "Next" twenty times.

It installs everything through winget, the package manager that comes with Windows, so the apps come from their official sources.

Browsers
Brave, Firefox, Chrome, Opera GX, Vivaldi
Media
Spotify, VLC, OBS Studio, Audacity, GIMP, Blender
Coding
VS Code, Git, Node.js, Python, Docker, Notepad++
Everyday
7-Zip, LibreOffice, Acrobat Reader, Bitwarden, PowerToys

Apps you already have are detected and skipped. It can also set your default browser.

How to use it

  1. Download the file above. If your browser asks, choose Keep.
  2. Right-click PostFormatInstaller.ps1 and choose Run with PowerShell. On Windows 11 it's under Show more options. Don't pick "Run as administrator".
  3. Tick the apps you want and press Install.
  4. When the bottom of the window says Finished, close it.

Windows will ask for permission for some apps. Before you click Yes, check that the name and the publisher match an app you picked, for example "Steam Setup" from Valve Corp. If something looks wrong, click No. That app is skipped and the rest keep going.

Is it safe?

It's a single plain-text script. You can open it in Notepad, or read it on GitHub, before running it. It has no ads, no tracking and no account. This exact file was checked by more than 70 antivirus engines on VirusTotal.

To make sure your copy is the same file, run Get-FileHash .\PostFormatInstaller.ps1 in PowerShell. The result should be:
